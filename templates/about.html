About This Project

This web application is developed as part of an intensive 8-week DIY internship project, showcasing modern Python web development using the Flask framework.

Project Roadmap

Week 1

Project Setup & Routing

Environment configuration, Jinja2 template inheritance, and core routing. (Current Stage)

Week 2

User Authentication

Registration, secure password hashing, and user login with Flask-Login.

Week 3

Blog Post CRUD

Database models with Flask-SQLAlchemy, create, read, update, and delete posts.

Week 4-8

UI, Comments & Launch

Responsive design, user comments, search & filters, and deployment.

Technology Stack

  • Backend: Python 3, Flask
  • Templating: Jinja2
  • Frontend: HTML5, CSS3, JavaScript
  • Database (Coming Week 3): SQLite & Flask-SQLAlchemy
